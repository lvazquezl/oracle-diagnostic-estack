# Reports

Entregables binarios (DOCX/XLSX/PDF/PPTX) generados por `technical-documentation-manager` bajo demanda explícita (`/document`), siempre derivados de un `analysis/ANA-*`/`INC-*` existente. Ver `workflows/document.md`, `templates/`.

Reportes reales no se versionan (ver `.gitignore` y `DISTRIBUTION.md`).
